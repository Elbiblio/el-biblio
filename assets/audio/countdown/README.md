# Countdown Audio Files

Pre-recorded audio files for meditation countdown numbers.

## Files Required:
- `1.mp3` - "One"
- `2.mp3` - "Two" 
- `3.mp3` - "Three"
- `4.mp3` - "Four"
- `5.mp3` - "Five"
- `6.mp3` - "Six"
- `7.mp3` - "Seven"
- `8.mp3` - "Eight"
- `9.mp3` - "Nine"
- `10.mp3` - "Ten"

## Recording Guidelines:
- Format: MP3, 44.1kHz, 128kbps
- Voice: Calm, gentle, meditation-appropriate
- Duration: ~1 second per number
- Volume: Consistent across all files
- No background music or effects

## Fallback:
If files are missing, the system will use TTS or generate simple tones.
