# Meditation Prompt Audio Files

Pre-recorded audio files for common meditation prompts.

## Files Required:
- `begin_meditation.mp3` - "Begin your meditation"
- `focus_breath.mp3` - "Focus on your breath"
- `return_awareness.mp3` - "Return to awareness"
- `let_go_thoughts.mp3` - "Let go of thoughts"
- `breathe_deeply.mp3` - "Breathe deeply"
- `find_comfort.mp3` - "Find comfort in stillness"

## Recording Guidelines:
- Format: MP3, 44.1kHz, 128kbps
- Voice: Same voice as countdown files
- Duration: 2-3 seconds per prompt
- Tone: Gentle, encouraging, meditative
- Volume: Consistent with countdown files

## Usage:
These files serve as the final fallback when:
1. Cloud TTS API is unavailable
2. System TTS fails to initialize
3. Network connectivity issues

## Alternative:
If files are missing, the system will use a gentle chime sound.
